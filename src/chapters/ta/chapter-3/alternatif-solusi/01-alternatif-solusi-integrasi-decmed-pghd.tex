\subsection{Alternatif Arsitektur Pengumpulan dan Pipeline PGHD-DecMed}\label{alternatif-arsitektur-pipeline-pghd}

Berdasarkan analisis permasalahan di atas, terdapat beberapa arsitektur yang dipertimbangkan.

\subsubsection{Wearable Device}

Data PGHD bisa diambil dari wearable device seperti smartwatch ataupun IoT device lainnya.
Terdapat beberapa pertimbangan terkait keterlibatan dan integrasi wearable device.

\begin{enumerate}
    \item Hanya menggunakan sensor bawaan Android (tanpa wearable).
    \item Mengintegrasikan data dari wearable fisik ke Android.
    \item Mensimulasikan wearable via BLE (tanpa perangkat fisik).
\end{enumerate}

Pada alternatif ini, pengumpulan data PGHD sepenuhnya dilakukan menggunakan API sensor yang tersedia di sistem operasi Android, yaitu Android Sensor API (akselerometer, giroskop, barometer, dsb.) dan Android Health Connect API (detak jantung, langkah kaki, tidur, saturasi oksigen, dll.). 
Data wearable tidak diambil sama sekali dalam cakupan implementasi.
