\subsubsection{Pengumpulan Data dari Sumber PGHD}

Klien pasien mengumpulkan data dari tiga sumber utama:

\begin{enumerate}
    \item \textbf{Sensor internal perangkat}: 
    Klien mengakses sensor bawaan \textit{smartphone} yang tersedia melalui API Android/iOS\@. 
    Izin akses diminta saat pertama kali aplikasi dijalankan.
    
    \item \textbf{Perangkat \textit{wearable}}: Klien terhubung ke perangkat \textit{wearable} (smartwatch, fitness tracker) melalui Bluetooth. 
\end{enumerate}

\subsubsection{Proxy Layer dan Smart Contract}

Proxy Layer berperan sebagai \textit{middleware} yang memproses permintaan dari klien pasien dan klien tenaga kesehatan. 
Untuk PGHD, proxy menyediakan \textit{endpoint} berikut:

\begin{itemize}
    \item \verb|POST /pghd|: menerima \textit{batch} PGHD dari klien pasien, mengunggah \verb|enc_pghd| ke IPFS, dan memanggil \verb|submit_pghd| pada \textit{smart contract}
    \item \verb|GET /pghd|: mengembalikan daftar PGHD milik pasien untuk tenaga kesehatan
    \item \verb|GET /pghd/{index}|: mengambil satu entri PGHD tertentu, melakukan verifikasi hash, re-encryption, dan mengembalikan data ke klien
\end{itemize}

\textit{Smart contract} di IOTA menyimpan metadata PGHD untuk setiap entri mengikuti format pada Tabel~\ref{tab:iota-pghd-metadata}.
