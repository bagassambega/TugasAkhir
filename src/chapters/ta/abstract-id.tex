	Sistem Rekam Medis Elektronik (RME) terdesentralisasi DecMed berbasis IOTA telah dikembangkan untuk mengatasi keterbatasan interoperabilitas dan keamanan data pada RME konvensional. 
	Namun, DecMed masih bersifat \emph{provider-centric} karena seluruh entri data hanya berasal dari tenaga kesehatan melalui kunjungan klinis. 
	Kondisi ini menciptakan kesenjangan informasi karena banyak kondisi medis memerlukan data \emph{between-visit} untuk mendukung pengambilan keputusan klinis yang akurat. 
	Untuk menjembatani kesenjangan tersebut, diperlukan integrasi \emph{Patient-Generated Health Data} (PGHD) ke dalam ekosistem DecMed, yaitu data kesehatan yang dihasilkan secara mandiri oleh pasien melalui perangkat \emph{wearable}, sensor, maupun input manual.
	Namun integrasi ini memunculkan tantangan dari sisi pengelolaan data \emph{time-series} bervolume tinggi, manajemen kondisi \emph{offline}, serta kebutuhan jaminan kerahasiaan, integritas, ketersediaan, dan \emph{data provenance}.

	Tugas akhir ini merancang dan mengimplementasikan \emph{integration pipeline}
	PGHD ke dalam ekosistem DecMed. 
	Pendekatan \emph{offline-first} dengan penyimpanan lokal dan mekanisme \emph{batching} diterapkan untuk mengelola volume data \emph{time-series} secara efisien. 
	Arsitektur sistem mengintegrasikan komponen \emph{client} Android PGHD Pasien, \emph{Proxy Re-Encryption} (PRE) Server, \emph{smart contract} IOTA, dan penyimpanan terdesentralisasi IPFS\@. 
	
	Dari sisi implementasi, kerahasiaan data dijamin melalui enkripsi \emph{end-to-end} berbasis AES-GCM di sisi \emph{client} dan mekanisme Proxy Re-Encryption untuk delegasi akses. 
	Integritas data dijamin melalui fungsi hash SHA-256 dan tanda tangan digital ECDSA, sementara \emph{data provenance} dicatat pada metadata \emph{smart contract} IOTA dan \emph{payload} IPFS\@. 
	Ketersediaan data diwujudkan melalui mekanisme \emph{offline-first} dengan penjadwalan ulang otomatis. 
	
	Pengujian \emph{smart contract}, fungsional, dan non-fungsional menunjukkan
	bahwa seluruh skenario berhasil. 
	Sistem berhasil memproses \emph{record} sintetis dalam volume besar tanpa kehilangan data, mendeteksi dan menolak seluruh variasi manipulasi integritas dan kerahasiaan, memastikan kelengkapan \emph{field provenance} pada setiap entri PGHD, serta mempertahankan data saat perangkat dalam kondisi luring dan memulihkannya setelah koneksi kembali tersedia.
	Hasil ini menunjukkan bahwa integrasi PGHD pada DecMed dapat terwujud dengan
	jaminan keamanan dan kepercayaan data yang komprehensif.
